# hsk5-drill.html — เวอร์ชันไฟล์เดียว

แอปฝึกรายวันที่ทำงานได้ครบในไฟล์ HTML ไฟล์เดียว
**ไม่ต้องล็อกอิน ไม่ต้องติดตั้ง ไม่ต้องมีเน็ตหลังโหลดเสร็จ**

มีไว้ให้ผู้เรียนเริ่มใช้ได้ทันทีระหว่างที่ระบบ Django ยังสร้างไม่เสร็จ
อย่าให้ผู้เรียนรอระบบ — ทุกวันที่รอคือคำที่ไม่ได้เรียน

## ข้อจำกัดที่ต้องรู้

**ความคืบหน้าเก็บในเบราว์เซอร์เครื่องนั้นเครื่องเดียว** (localStorage)

- เปลี่ยนเครื่อง / เปลี่ยนเบราว์เซอร์ / ล้างข้อมูลเว็บ = ข้อมูลหาย
- คนสร้างระบบ **มองไม่เห็น**ความคืบหน้าของผู้เรียนจากระยะไกล

วิธีแก้ชั่วคราว: ให้ผู้เรียนกด **ข้อมูล → ดาวน์โหลดข้อมูลทั้งหมด** ทุกสัปดาห์
แล้วส่งไฟล์ `hsk5-backup.json` กลับมา

การแก้จริงคือ Sprint 2–5 (Django + deploy VPS) ซึ่งจะได้ทั้ง sync ข้ามเครื่อง
และ coach dashboard ที่เห็นความคืบหน้าแบบสด

## สิ่งที่มีในแอป

- **วันนี้** — บอกว่ามีอะไรถึงกำหนด ชุดวันนี้ประกอบด้วยอะไร มีปุ่มเริ่ม
- **ทำข้อสอบ** — 40 ข้อคงที่ คละ 4 แบบ: เลือกความหมาย · นึกคำจากความหมาย · เลือกคำใกล้เคียง · เรียงประโยค 完成句子
- **สถิติ** — กราฟความแม่นรายวัน · กราฟคำสะสมเทียบเส้นเป้า · แท่งสาเหตุที่ผิด · นับถอยหลังจุดตัดสินใจ
- **ข้อผิด** — คำที่ผิดบ่อยสุดขึ้นก่อน ส่งออก CSV เข้า Anki ได้
- **เขียน** — เทมเพลตเรียงความ 3 แบบ + prompt สำหรับให้ AI ตรวจงานเขียน
- **ข้อมูล** — นำเข้าคำศัพท์เพิ่ม (วางลิสต์ HSK5 เต็มได้) · สำรองข้อมูล

คลังตั้งต้น 109 คำ — เป็นคำที่ให้ผลตอบแทนสูงสุด ไม่ใช่คำที่มาก่อนตามตัวอักษร

## เพิ่มคำศัพท์

แท็บ **ข้อมูล** วางทีละบรรทัด:

```
影响 | yǐngxiǎng | ส่งผลกระทบ | 天气影响了我们的计划。
```

ช่องที่ 4 (ประโยคตัวอย่าง) ไม่ใส่ก็ได้ วางลิสต์ยาวๆ ทีเดียวได้เลย
