| ไฟล์ | คืออะไร |

- ความถี่: SUBTLEX-CH (Cai & Brysbaert 2010)
- ความหมายไทย ประโยคตัวอย่าง คำอธิบาย: สร้างด้วย AI แล้วตรวจข้ามด้วยเครื่องมือและ agent อิสระ
  **ยังไม่มีเจ้าของภาษาตรวจ** — อ่าน `QUALITY_REPORT.md` ก่อนใช้สอน

## `exam_fixture.json`

ข้อสอบตัวอย่าง HSK5 ทางการ 9 ชุด (H51001-H51005, H51327, H51328, H51330, H51332)
ที่แกะจาก PDF และแยกโครงสร้างแล้ว — 924 ข้อ · 3,288 ตัวเลือก · 81 บทอ่าน

**ที่มา:** ข้อสอบตัวอย่างที่ 国家汉办 / Chinese Testing International เปิดให้ดาวน์โหลด

**ลิขสิทธิ์:** เป็นของผู้จัดสอบ ไม่ใช่ของโปรเจกต์นี้ ทุกเรคคอร์ดจึงติดป้าย
`source_type = "official_past_paper"` และ `commercial_safe = false` ในฐานข้อมูล
ใช้เพื่อการเรียนและเตรียมสอบเท่านั้น **ห้ามนำไปใช้เชิงพาณิชย์**

นำเข้าฐานข้อมูลด้วย:

```bash
python manage.py loaddata data/exam_fixture.json
```

หรือสร้างใหม่จาก PDF ต้นฉบับ (ไม่ได้อยู่ในรีโป) ด้วย `python manage.py import_exams`
